## 测试目标

后端在 2026-06-14 更新后，多个原本只接受单数 id 的接口新增了**数组批量**形式（`link_ids`/`node_ids`/`nodes`/`links`/`device_configs`）或 **`fields` 按需字段**，本阶段补充测试这些新能力：

- `link_capture_start` / `link_capture_stop` / `link_capture_download` 接受 `link_ids:[...]`，一次多条
- `link_reset` / `link_delete` 接受 `link_ids:[...]`，一次多条
- `node_create` 接受 `nodes:[...]`，一次建多个节点
- `node_start` / `node_stop` / `node_reload` / `node_suspend` / `node_delete` 接受 `node_ids:[...]`，一次多个
- `link_create` 接受 `links:[...]`，一次多条链路
- `device_config_send` / `device_command_run` / `vpcs_config_set` 接受 `device_configs:[...]`，一次多节点
- `link_list` / `appliance_list` 支持 `fields:[...]` 按需返回字段省 token

背景：阶段 8（数据包捕获）只测了单数 `link_id`；阶段 10（节点生命周期）只测了单数 `node_id` 和 `*_all` 全量。本阶段补上**指定子集**的数组批量 + fields。

### 测试 14.3: 批量获取下载链接（link_capture_download + link_ids）

**工具**: `mcp__My_GNS3_Server__link_capture_download`  
**执行时间**: 2026-06-14 21:09  
**参数**: `project_id`, `link_ids:[id1,id2]`

#### 执行命令
```json
{
  "project_id": "85835ce2-...",
  "link_ids": ["4a9c49a9-...", "4a290b77-..."]
}
```

#### 返回结果
```json
{
  "downloads": [
    {
      "link_id": "4a9c49a9-...",
      "download_url": "http://.../capture/file",
      "curl_command": "curl -L -o capture_4a9c49a9-....pcap -H 'Authorization: Bearer <JWT>' 'http://...'"
    },
    {
      "link_id": "4a290b77-...",
      "download_url": "http://.../capture/file",
      "curl_command": "curl -L -o capture_4a290b77-....pcap -H 'Authorization: Bearer <JWT>' 'http://...'"
    }
  ],
  "count": 2,
  "note": "Files are in pcap format. Links include a 10-minute token."
}
```

#### 结果分析

**✅ 批量获取下载链接成功**
- 返回结构不同于 start/stop，包了一层 `downloads:{...}` + `count`
- 每条 `curl_command` 的输出文件名**自动带 link_id**（如 `capture_4a9c49a9-....pcap`），不会重名
- 同一批共用 1 个 JWT（`Authorization: Bearer` 头，10 分钟有效期）

> ⚠️ `link_capture_download` 的数组模式为**串行**处理（非并行），其余批量接口均为并行。

#### 测试结论
✅ **测试成功** - 一次返回多个下载链接，curl 并行下载即可

### 测试 14.4: 并行下载 pcap（curl 多 & + wait）

**工具**: `curl`（shell 侧）  
**执行时间**: 2026-06-14 21:09  
**参数**: token + 多 URL 并行

#### 执行命令
```bash
TOK='<JWT>'
curl -L -s -o e0-1.pcap -H "Authorization: Bearer $TOK" "$BASE/4a9c49a9-.../capture/file" &
curl -L -s -o e0-2.pcap -H "Authorization: Bearer $TOK" "$BASE/4a290b77-.../capture/file" &
wait
```

#### 返回结果
```
e0-1.pcap: 6323 B, 52 packets, 30 ICMP
e0-2.pcap: 6323 B, 52 packets, 30 ICMP
```

#### 结果分析

**✅ curl 并行下载有效**
- 两次 `curl &` + `wait` 同时拉两个 pcap
- 各 52 包（含注入的 30 ICMP + BGP keepalive + L2 噪声），数据完整，可用 tshark 直接分析

#### 测试结论
✅ **测试成功** - 一次下载多个 pcap，无需逐条 curl
